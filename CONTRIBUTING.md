# Contributing zu Luna Assistant

Wir freuen uns über Beiträge! Hier sind ein paar Richtlinien:

## Wie du beitragen kannst

1. **Fork** das Repository
2. **Erstelle einen Branch** für deine Feature (`git checkout -b feature/AmazingFeature`)
3. **Commit** deine Änderungen (`git commit -m 'Add some AmazingFeature'`)
4. **Push** zu deinem Branch (`git push origin feature/AmazingFeature`)
5. **Öffne einen Pull Request**

## Ideen für neue Features

- Neue Begleitungs-Modi hinzufügen
- Benachrichtigungssystem verbessern
- Voice-Funktionalität hinzufügen
- Mobile App entwickeln
- Integrations mit anderen Services (Spotify, Fitness-Apps, etc.)
- AI-Responses verbessern
- Community-Features erweitern
