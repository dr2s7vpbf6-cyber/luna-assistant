# 🌙 Luna Assistant

Ein intelligenter, persönlicher KI-Assistent speziell für Frauen. Luna begleitet dich in verschiedenen Lebensbereichen und passt sich deinen Bedürfnissen an.

## Features

✨ **Personalisierbare Begleitungs-Modi:**
- 👗 **Outfit & Style** - Styling-Tipps, Outfit-Vorschläge, Mode-Beratung
- 🛍️ **Shopping & Sales** - Produkt-Empfehlungen, Deal-Alerts, Einkaufsbegleitung
- 💪 **Fitness & Gesundheit** - Trainings-Pläne, Ernährungstipps, Wellness
- 💼 **Karriere & Networking** - Job-Suche, Bewerbungstipps, Karriere-Planung
- 🧘 **Mindfulness & Selbstliebe** - Meditation, Affirmationen, Selbstpflege
- 📚 **Bildung & Wissen** - Lern-Tipps, Kurse, Skill-Entwicklung
- 👥 **Beziehungen & Community** - Ratschläge, Events, Networking
- 💰 **Finanzen & Sparen** - Budget-Planung, Sparstrategien, Finanz-Tipps
- 📅 **Alltag & Produktivität** - To-Do-Listen, Erinnerungen, Zeitmanagement

## Wie es funktioniert

1. **Registrierung** - Erstelle dein Luna-Profil
2. **Wähle deine Modi** - Entscheide selbst, wobei Luna dich begleiten soll
3. **Chatte mit Luna** - Erhalte personalisierte Unterstützung
4. **Erhalte Benachrichtigungen** - Erinnerungen und hilfreiche Tipps im richtigen Moment

## Tech Stack

- **Frontend:** React / Next.js
- **Backend:** Python Flask / FastAPI
- **AI:** OpenAI / Hugging Face
- **Database:** PostgreSQL
- **Real-time:** WebSockets

## Installation

```bash
git clone https://github.com/dr2s7vpbf6-cyber/luna-assistant.git
cd luna-assistant

# Backend
cd backend
pip install -r requirements.txt
python app.py

# Frontend
cd ../frontend
npm install
npm run dev
```
